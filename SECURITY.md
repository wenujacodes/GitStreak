## Reporting a Vulnerability

We take the security of GitStreak seriously. If you discover a security vulnerability, please follow these steps to report it responsibly.

### How to Report

1. **GitHub Private Vulnerability Reporting (Preferred)**:
   - Navigate to the [GitStreak Security Advisories](https://github.com/wenujacodes/GitStreak/security/advisories) page on GitHub.
   - Click on **"Report a vulnerability"** to submit a private report.

2. **Alternative Contact**:
   - If GitHub Private Vulnerability Reporting is unavailable, please open a GitHub Issue with minimal details and request a private communication channel, or reach out to the project maintainer directly.

> [!IMPORTANT]
> **Please do not report security vulnerabilities through public GitHub issues or public discussions.**

---

## What to Expect

When you report a vulnerability:

* **Initial Response**: You will receive an acknowledgment of your report within **48 hours**.
* **Assessment & Updates**: We will investigate the issue and provide updates on progress at least once every **3 to 5 business days**.
* **Resolution**:
  * **If Accepted**: A patch will be developed, tested, and released in an upcoming version (distributed via Sparkle automatic updates and GitHub Releases). You will be credited in the release notes if you wish.
  * **If Declined**: We will provide a detailed explanation of why the reported issue is not considered a security vulnerability or security risk.
